# Blurapp

**가림**

아이폰에서 사진 속 얼굴을 선택해 모자이크하는 한국어 네이티브 앱입니다. SwiftUI로 화면을 구성하고 Apple Vision으로 얼굴 위치를 찾습니다. Core Image가 선택한 영역에만 픽셀 모자이크를 적용합니다.

## 실행

1. Mac에서 Xcode 15 이상으로 `Garim.xcodeproj`를 엽니다.
2. 상단의 `Garim` 스킴과 iOS 17 이상 iPhone 시뮬레이터를 선택하고 ⌘R을 누릅니다.
3. 실제 아이폰에서 실행할 때는 앱 타깃의 **Signing & Capabilities → Team**에서 본인의 개발 팀을 선택합니다. 번들 ID가 이미 등록돼 있으면 본인 계정에서 쓸 고유한 값으로 바꿉니다. 연결한 아이폰을 실행 대상으로 선택합니다.

테스트는 같은 스킴의 **Product → Test**(⌘U)로 실행할 수 있습니다. 좌표 변환, 수동 영역 경계, 회전된 이미지에서의 선택적 모자이크, JPEG 내보내기를 검사합니다.

## 사용

- **사진 선택하기**에서 사진 한 장을 고릅니다. 처음에는 찾아낸 얼굴을 전부 가립니다.
- 남길 얼굴을 사진이나 번호 목록에서 누릅니다. 다시 누르면 가립니다.
- 옆얼굴이나 작은 얼굴을 놓쳤다면 **직접 추가**를 누르고 사진 위에서 사각형을 그립니다. 수동 영역도 번호 목록에서 켜거나 끌 수 있습니다.
- 강도를 고르고 **결과 보기**에서 표시선을 숨겨 확인합니다. **새 사진으로 저장**하면 사진 보관함에 JPEG 한 장을 추가합니다.

## 사진 처리

앱은 가져온 사진과 편집 상태를 메모리에 두고 기기 안에서 처리합니다. 앱에 네트워크 호출, 분석 SDK, 계정, 외부 패키지가 없습니다. 사진 선택은 시스템 사진 선택기를 사용하며 저장 시 사진 추가 권한을 요청합니다. iCloud에만 있는 입력은 시스템 사진 선택기가 가져올 수 있고, 저장한 사본은 사용자의 iCloud 사진 설정을 따릅니다.

편집 미리보기는 긴 변 최대 1,920픽셀, 저장 사본은 긴 변 최대 4,096픽셀입니다. 작은 원본의 크기와 사진 비율을 유지합니다. 저장 사본에는 모자이크가 픽셀로 반영되고 입력 파일의 위치 정보와 EXIF를 옮기지 않습니다. Live Photo는 정지 사진으로 처리합니다.
