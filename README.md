# Blurapp

**가림**

아이폰에서 사진 속 얼굴이나 원하는 부분을 가리는 한국어 네이티브 앱입니다. SwiftUI로 화면을 구성하고 Apple Vision으로 얼굴과 사람·물체를 찾습니다. Core Image가 모자이크·블러 같은 효과를 고른 영역에만, 또는 고른 대상을 뺀 나머지 전체에 적용합니다.

- 사진을 한 번에 최대 20장까지 골라 한 장씩 다듬고 **모두 저장**으로 한꺼번에 저장합니다.
- 효과 5가지: 모자이크, 육각 모자이크, 크리스털, 블러, 검정 가림. 강도는 약하게·보통·강하게 중에서 고릅니다.
- **골라서 남기기**: 고른 사람이나 물체만 남기고 나머지를 모두 가립니다.

## IPA 받기

[Releases](https://github.com/wnddud0818/Blurapp/releases)에서 `Garim-<버전>-unsigned.ipa`를 내려받습니다. 서명하지 않은 IPA라서 AltStore, SideStore, Sideloadly 같은 사이드로딩 도구로 설치하면 도구가 본인 Apple ID로 서명합니다. 무료 Apple ID로 설치한 앱은 7일마다 갱신해야 하고, iOS 16 이상에서는 **설정 → 개인정보 보호 및 보안 → 개발자 모드**를 켜야 합니다.

릴리즈 IPA는 Mac에서 직접 빌드해 올립니다. GitHub Actions는 사용하지 않습니다.

Xcode와 [GitHub CLI](https://cli.github.com)(`gh auth login`)가 있는 Mac에서 `scripts/publish-ipa.sh v1.1.0`을 실행합니다. 태그가 이미 GitHub에 있으면 먼저 `git checkout v1.1.0`으로 그 커밋을 받고, 없으면 지금 커밋(먼저 푸시해야 함)에 태그를 만듭니다. IPA 파일만 필요하면 `scripts/build-ipa.sh`를 실행합니다.

## 실행

1. Mac에서 Xcode 15 이상으로 `Garim.xcodeproj`를 엽니다.
2. 상단의 `Garim` 스킴과 iOS 17 이상 iPhone 시뮬레이터를 선택하고 ⌘R을 누릅니다.
3. 실제 아이폰에서 실행할 때는 앱 타깃의 **Signing & Capabilities → Team**에서 본인의 개발 팀을 선택합니다. 번들 ID가 이미 등록돼 있으면 본인 계정에서 쓸 고유한 값으로 바꿉니다. 연결한 아이폰을 실행 대상으로 선택합니다.

테스트는 같은 스킴의 **Product → Test**(⌘U)로 실행할 수 있습니다. 좌표 변환, 수동 영역 경계, 회전된 이미지에서의 선택적 모자이크, 모든 효과가 고른 영역 안에만 적용되는지, 고른 대상만 남기는 합성, 사람·물체 지도의 선택과 마스크, JPEG 내보내기를 검사합니다.

사람·물체 분리(`VNGenerateForegroundInstanceMaskRequest`)는 시뮬레이터에서 동작하지 않습니다. 시뮬레이터에서는 **골라서 남기기**가 자동 분리 대신 직접 그린 영역만 남기며, 실제 기기에서 확인합니다.

## iPhone Duo에서 실행

Duo의 전체 디스플레이를 사용하려면 Xcode 27.1 이상(iOS 27.1 SDK 이상)에서 빌드합니다. 일반 아이폰의 최소 지원 버전은 iOS 17입니다.

1. 실행 대상으로 **iPhone Duo**를 선택하고 사진을 열어 얼굴 하나를 남긴 뒤 수동 영역도 추가합니다.
2. Device Hub에서 기기를 펼치면 사진 옆에 편집 도구가 나타납니다. 닫거나 좁은 Split View로 전환하면 도구가 사진 아래로 이동합니다. 접근성용 큰 글씨에서는 한 열로 편집합니다.
3. 접고 펴거나 회전한 뒤 같은 얼굴과 수동 영역이 가려지는지 확인합니다. **결과 보기**에서 확인한 후 **새 사진으로 저장**합니다.

[Apple의 iPhone Duo 개발 가이드](https://developer.apple.com/kr/iphone-duo/prepare/)

## 사용

- **사진 선택하기**에서 사진을 한 장 이상 고릅니다(최대 20장). 고른 순서대로 위쪽 사진 줄에 놓이고, 썸네일을 눌러 편집할 사진을 바꿉니다. **+** 또는 **사진 → 사진 추가**로 더 넣고, 썸네일을 길게 눌러 목록에서 뺍니다.
- **가리는 방식**을 고릅니다.
  - **골라서 가리기**: 처음에는 찾아낸 얼굴을 전부 가립니다. 남길 얼굴을 사진이나 번호 목록에서 누르면 풀리고, 다시 누르면 가립니다. 놓친 얼굴은 **직접 추가**를 누르고 사진 위에 사각형을 그립니다.
  - **골라서 남기기**: 사진 속 사람·동물·물체를 찾아 번호를 붙입니다. 처음에는 사람(없으면 가장 큰 대상) 하나만 남기고 나머지를 모두 가립니다. 남길 대상을 사진에서 직접 누르거나 목록에서 켜고 끕니다. 자동으로 찾지 못한 부분은 **직접 추가**로 남길 사각형을 그립니다.
- **효과**(모자이크·육각 모자이크·크리스털·블러·검정 가림)와 **강도**를 고릅니다. 가리는 방식, 효과, 강도는 모든 사진에 똑같이 적용되고, 얼굴·대상 선택은 사진마다 따로 저장됩니다.
- **골라서 남기기**에서 **모두 저장**은 한 번이라도 열어서 남길 대상을 확인한 사진만 저장합니다. 확인하지 않은 사진 수는 저장 버튼 아래에 표시됩니다.
- **결과 보기**에서 표시선을 숨겨 확인합니다. 한 장이면 **새 사진으로 저장**, 여러 장이면 **모두 저장**이나 **이 사진만 저장**을 누릅니다. 저장한 사진은 썸네일에 체크 표시가 붙고, 원본은 그대로 둔 채 사진 보관함에 JPEG를 새로 추가합니다.

## 사진 처리

앱은 가져온 사진과 편집 상태를 메모리에 두고 기기 안에서 처리합니다. 여러 장을 고르면 원본 데이터와 작은 썸네일만 들고 있고, 편집 미리보기는 보고 있는 사진만 만듭니다. 한 번에 불러오는 원본은 합계 600MB까지입니다. 앱에 네트워크 호출, 분석 SDK, 계정, 외부 패키지가 없습니다. 사진 선택은 시스템 사진 선택기를 사용하며 저장 시 사진 추가 권한을 요청합니다. iCloud에만 있는 입력은 시스템 사진 선택기가 가져올 수 있고, 저장한 사본은 사용자의 iCloud 사진 설정을 따릅니다.

편집 미리보기는 긴 변 최대 1,920픽셀, 저장 사본은 긴 변 최대 4,096픽셀입니다. 작은 원본의 크기와 사진 비율을 유지합니다. 저장 사본에는 모자이크가 픽셀로 반영되고 입력 파일의 위치 정보와 EXIF를 옮기지 않습니다. Live Photo는 정지 사진으로 처리합니다.
